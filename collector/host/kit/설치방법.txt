꽁보다 모터스포츠 F1 수집기 설치 방법 (Windows)
================================================

이 프로그램은 무엇인가요?
- F1 세션(연습·퀄리파잉·스프린트·레이스) 동안 공식 실시간 타이밍을 받아
  꽁보다 사이트에 올려 주는 수집기입니다.
- F1이 클라우드 서버 접속을 막아서, 집 인터넷에 연결된 PC가 대신 받아 줍니다.
- 한 번 설치하면 PC를 켜고 Windows에 로그인만 하면 알아서 동작합니다.

준비물
- Windows 10 또는 11 PC
- 본인 F1 계정 (F1 TV Access 이상 구독)
- 집 인터넷 (VPN, 회사·학교 망은 F1이 막을 수 있습니다)
- 노트북이면 충전기

설치 순서
1. 이 압축 파일을 원하는 폴더에 "압축 풀기" 합니다. (압축 안에서 바로 실행하지 마세요)
2. "1_설치하기.cmd" 를 더블클릭합니다.
   - 예비 PC로 둘 거면 "2_예비_PC로_설치하기.cmd" 를 대신 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
3. 검은 창에 F1 account email / password 를 물으면 본인 F1 계정을 입력합니다.
   비밀번호는 입력해도 화면에 안 보이는 게 정상입니다.
4. 설치가 끝나면 메모장에 "내_호스트_키.txt" 가 열립니다.
   이 파일 내용을 운영자(정민)에게 보내 주세요. 공개해도 되는 값입니다.
5. 운영자가 등록했다고 하면 "3_상태_확인.cmd" 를 실행해
   "등록됨" 과 "F1 실시간 타이밍 접속: 가능" 이 나오는지 확인합니다.

설치하면 자동으로 바뀌는 것
- Windows 로그인 때 수집기가 숨겨진 창으로 자동 시작됩니다.
- 전원이 연결돼 있으면 PC가 절전에 들어가지 않고, 노트북 덮개를 닫아도 계속 켜져 있습니다.
- 세션 45분 전부터 세션이 끝날 때까지는 배터리 상태에서도 자동 절전이 막힙니다.
  (덮개를 닫거나 전원 버튼을 누르면 Windows 설정대로 동작합니다)
- 새 버전이 나오면 쉬는 시간에 알아서 업데이트됩니다. 세션 중에는 업데이트하지 않습니다.

평소 사용법
- 세션 15분 전쯤 PC를 켜고 Windows에 로그인만 하면 됩니다.
- 로그인 화면에 멈춰 있으면 수집이 시작되지 않습니다. (로그인 후 화면 잠금은 괜찮습니다)
- 레이스 주말에는 Windows 업데이트를 "일시 중지"해 두면 재부팅으로 끊기는 일을 막을 수 있습니다.

주 PC와 예비 PC
- 주 PC는 세션이 열리면 바로 수집합니다.
- 예비 PC는 세션 시작 2분 뒤에 다른 PC가 이미 올리고 있으면 기다리고,
  아무도 안 올리고 있을 때만 대신 수집합니다.

문제가 생기면
- "3_상태_확인.cmd" 결과 화면을 캡처해서 운영자에게 보내 주세요.
- 기록 파일 위치: %LOCALAPPDATA%\Kongboda\data\host.log, run-log.jsonl
  (탐색기 주소창에 붙여 넣으면 열립니다. 비밀번호는 들어 있지 않습니다)

지우고 싶을 때
- "4_제거하기.cmd" 를 실행하고 y 를 입력합니다.
- 운영자에게 알려 주면 이 PC 키를 목록에서 뺍니다.

개인정보
- F1 비밀번호는 이 PC의 %LOCALAPPDATA%\Kongboda\host.env 에만 저장되고,
  이 Windows 사용자만 읽을 수 있게 권한이 막혀 있습니다. 사이트로 보내지 않습니다.
