꽁보다 F1 수집기 설치하기 (Mac)
==============================

이게 뭐예요?
  F1 경기 기록을 받아서 꽁보다 사이트로 보내 주는 프로그램이에요.
  한 번만 설치하면 그다음부터는 Mac을 켜기만 하면 알아서 돌아가요.


[ 설치 전에 준비할 것 ]

  1. Mac (맥북, 아이맥, 맥 미니 다 돼요)
  2. F1 홈페이지 로그인 이메일과 비밀번호
     (F1 TV 유료 구독이 있는 계정이어야 해요)
  3. Mac 로그인 비밀번호 (Mac 켤 때 치는 비밀번호)
  4. 꽁보다 사이트에 로그인할 Google 계정
  5. 맥북이면 충전기를 꽂아 두세요


[ 설치하기 ]  (10분 정도 걸려요)

  1단계. 이 파일에서 아래 [설치 줄] 을 마우스로 끌어서 칠하고
         command 키 + C 를 누르세요. (복사)

  [설치 줄]
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/MisterKinn/f1-data-analyst/main/collector/host/kit-mac.sh)" - install

  2단계. command 키 + 스페이스바 를 누르세요.
         "터미널" 이라고 치고 Enter 키를 누르세요.
         (하얀 또는 검은 글자 창이 열려요)

  3단계. 터미널 창을 한 번 클릭하고
         command 키 + V 를 누르세요. (붙여넣기)
         그다음 Enter 키를 누르세요.

  4단계. 글자가 지나가요. 기다리세요.

  5단계. "F1 account email:" 이 나오면
         F1 이메일을 치고 Enter 키를 누르세요.

  6단계. "F1 account password:" 가 나오면
         F1 비밀번호를 치고 Enter 키를 누르세요.
         ※ 비밀번호는 쳐도 화면에 안 보여요. 정상이에요. 그냥 치세요.

  7단계. "Password:" 가 또 나오면
         이번에는 Mac 로그인 비밀번호를 치고 Enter 키를 누르세요.
         ※ 이것도 화면에 안 보여요. 정상이에요.
         ※ 안 나오면 그냥 넘어가요.

  8단계. 인터넷 창(꽁보다 사이트)이 저절로 열려요.
         "Google로 로그인" 을 누르고 내 Google 계정을 고르세요.
         그다음 "내 계정에 이 컴퓨터 연결" 버튼을 누르세요.
         ※ 이걸 해야 수집기로 등록돼요. 안 하면 수집을 안 해요.
         ※ 인터넷 창이 안 열리면 터미널에 나온 주소를
           Safari 주소칸에 붙여 넣으세요.

  9단계. 맨 아래에 "끝" 이 나오면 터미널 창을 닫으세요.
         (빨간 동그라미 버튼)

  10단계. 끝! 다음 F1 세션부터 자동으로 수집해요.
         (정민이한테 "설치했어" 라고 알려 주면 좋아요)

  설치 끝!


[ 잘 됐는지 확인하고 싶으면 ]

  설치할 때처럼 아래 [확인 줄] 을 복사해서
  터미널에 붙여넣고 Enter 키를 누르세요.

  [확인 줄]
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/MisterKinn/f1-data-analyst/main/collector/host/kit-mac.sh)" - check

  초록색 글자로 아래 두 줄이 나오면 성공이에요.
    - F1 실시간 타이밍 접속: 가능
    - 등록됨

  빨간색이나 노란색 글자가 나오면
  그 화면을 사진 찍어서 정민이한테 보내 주세요.


[ 평소에 할 일 ]

  F1 세션 전이든 세션 중이든 Mac을 켜고 로그인만 하세요.
  늦게 켜도 괜찮아요. 놓친 기록은 F1 공식 기록에서 알아서 채워요.
  그게 끝이에요. 나머지는 알아서 해요.

  ※ 맥북은 충전기를 꽂아 두세요.
  ※ 맥북 화면(뚜껑)을 덮으면 잠들어요. 경기 중에는 열어 두세요.
     (외부 모니터를 연결해 둔 경우는 덮어도 돼요)
  ※ 경기 중에는 Mac을 끄지 마세요.


[ 이런 건 신경 안 써도 돼요 ]

  - 경기 중에는 Mac이 저절로 잠들지 않아요.
  - 새 버전은 알아서 업데이트돼요.
  - 비밀번호는 이 Mac에만 저장되고 다른 곳으로 보내지지 않아요.
  - 컴퓨터가 여러 대면 순서는 정민이가 사이트에서 정해요.


[ 지우고 싶을 때 ]

  아래 [제거 줄] 을 복사해서 터미널에 붙여넣고 Enter 키를 누르세요.
  "y" 를 치고 Enter 키를 누르세요.

  [제거 줄]
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/MisterKinn/f1-data-analyst/main/collector/host/kit-mac.sh)" - uninstall

  그리고 정민이한테 "지웠어" 라고 알려 주세요.


[ 안 될 때 ]

  - 회사·학교 인터넷이나 VPN에서는 안 될 수 있어요. 집 인터넷에서 하세요.
  - "command not found" 나 빨간 글자가 나오면
    그 화면을 사진 찍어서 정민이한테 보내 주세요.
  - 뭐든 이상하면 화면 사진을 정민이한테 보내 주세요.
