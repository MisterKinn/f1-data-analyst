# 수집기 점검 및 보완 — 2026-10-31

## 관측과 원인

- 운영 Render 로그에서 22:40:27 UTC 프로세스 시작, 22:40:37 WEC 준비 시작, 22:41:51 WEC 준비 완료를 확인했다. 이는 서버 재시작의 증거다. 재시작 자체의 플랫폼 원인은 로그 범위에서 확정하지 못했다.
- 이전 소스는 WEC 준비를 동기 실행한 후 F1 supervisor를 시작했다. WEC 지연·실패가 F1 시작을 막을 수 있었다. 비동기 분리하고 WEC 실패에도 F1·HTTP health를 유지한다. WEC는 기존 별도 자식 프로세스·잠금·저장소를 사용하며 F1 pause/stop은 WEC를 건드리지 않는다. 두 대회의 동시 실행을 전제로 한다. 공유 호스트 장애까지 분리된 물리 인프라라고 보장하지 않는다.
- 이전 수집기는 체크포인트가 있으면 완성 랩을 복원했지만 임시 디스크가 사라지거나 늦게 시작한 세션의 과거 섹터를 재수집하지 않았다. 이제 같은 공식 세션의 스트림을 별도 State에서 재생하고 검증된 완주 랩만 합친다. 복구 패킷은 라이브 신선도를 갱신하지 않는다. 로컬 raw 재생도 지원한다. 세션 종료로 SignalR가 과거 세션을 더 이상 제공하지 않아도, 저장된 SessionInfo의 공식 경로로 비동기 사후 복구를 요청한다. 원시 clock 스트림이 없어 UTC 정렬이 불가능하면 FastF1 Session.load의 공식 타이밍·텔레메트리 파서로 복구하며, 같은 세션 경로·정확한 랩·섹터 합·삭제·피트 여부를 재검증한다. 이전 세션 복구가 현재 다른 세션의 저장본을 덮어쓰지 않게 한다. 단일 드라이버 사후 최고 랩 조회는 도구 목록이 캐시된 클라이언트에서도 사후 텔레메트리 로딩을 시도한다.
- 전체 초기 스냅샷을 rolling state와 합치면 재접속 전 삭제·철회된 필드가 남을 수 있었다. 이제 초기 토픽은 교체한다. 실제 증분 업데이트는 계속 merge한다.
- 최고 랩 총시간이 같은 다른 랩을 이미 명시된 랩 번호와 다르게 연결할 수 있었던 경로를 차단했다. 재생과 실시간의 밀리초 시각 차이로 같은 랩이 중복되는 경우도 합친다.
- 마지막 저장은 수신 생산자를 정지한 뒤 수행한다. 완주 기록은 체크포인트에 보존하고 snapshot에는 드라이버별 최근 12랩과 최고 랩을 전달한다. 복구 상태·섹터 확보율·거절된 시퀀스를 노출한다.

## 텔레메트리 수명

- 세션 중 CarData.z의 UTC·차량별 실제 샘플을 SQLite에 누적한다. 중복 UTC는 덮어써 재접속 중복을 제거한다. 원시 채널 0/2/3/4/5를 RPM/속도/기어/스로틀/이진 브레이크로 읽는다.
- 종료 상태 Finished 또는 Finalised를 관측한 시점부터 300초 후 누적 DB와 혼합 raw 파일, 저장 snapshot의 CarData.z/Position.z를 제거한다. 서비스가 가동 중일 때 5초 supervisor 주기로 처리한다. 검증된 랩·섹터 기록은 유지한다. 새 고빈도 배치는 공유 R2 snapshot에 저장하지 않는다.
- PC 수집기도 동일한 누적·만료 정책을 사용한다. PC가 꺼져 있으면 다음 실행 시 만료 정리를 수행한다. 서버·PC가 꺼진 동안 삭제 코드가 실행된다고 보장하지 않는다.
- 사후 분석은 FastF1 Session.load로 공식 세션 자료를 다시 불러온다. FastF1의 HTTP/계산 디스크 캐시는 이 작업에서 비활성화하고 결과 캐시는 5분 뒤 지운다. 진행 중인 세션에서 수신이 부족한 것을 과거 자료로 대체하지 않는다.
- 요청 처리 중 기존 데이터가 만료돼도 자동으로 사후 로딩을 시작한다. pending/busy/unavailable/partial/ready를 구분하며 원본 제공 지연과 로딩 실패를 정상 수신으로 보고하지 않는다.

## 조회·그래프

`fastf1_lap_telemetry`는 같은 세션의 실제 최고 랩 1~2개를 조회한다. 사후 자료는 정확한 드라이버·랩·총시간을 대조하고 IsAccurate, 삭제 및 피트 여부를 검증한다. 속도·스로틀·이진 브레이크·기어·RPM과 섹터를 반환한다. 경계 보간은 실제 이웃 샘플 사이에서만 하고 1.5초 넘는 누락을 메우지 않는다. 거리는 속도 적분 근사치다. 델타는 완전한 두 랩의 공통 관측 거리 안에서만 계산하며 공식 타이밍과 같은 정밀도라고 주장하지 않는다.

기존 인증·선원 권한을 새 도구에도 적용했다. 임의 URL·경로는 받지 않으며 확인된 세션 경로만 사용한다. 자격증명·토큰·쿠키와 오류 본문은 반환하지 않는다.
